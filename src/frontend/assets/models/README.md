# Model icons

`gemini.svg`, `openai.svg`, `anthropic.svg`, `nvidia.svg`, and `dotsstudio.svg` come from `@lobehub/icons-static-svg@1.95.1` (MIT). The original files use `currentColor`; Aedos renders them as monochrome CSS masks so they follow the active theme.

Source: https://unpkg.com/@lobehub/icons-static-svg@1.95.1/icons/
