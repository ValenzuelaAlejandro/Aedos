02 / 08

HNSW

HNSW: MUNDOS PEQUEÑOS NAVEGABLES JERÁRQUICOS

Construcción de Grafos Multicapa

ESTRUCTURA EN CAPAS: Cada nivel es un grafo no dirigido (SL).

PUNTO DE ENTRADA: Nodo inicial fijo para todas las búsquedas.

HEURÍSTICA DE INSERCIÓN: Asignación probabilística a capas basada en distancia.

ALGORITMO DE BÚSQUEDA: Recorrido codicioso desde punto de entrada, descendiendo entre capas.

PARÁMETROS CLAVE: M (conexiones máx. por nodo), efConstruction (exploración durante construcción), efSearch (exploración durante consulta).

OPCIONES ESTRATÉGICAS DE IMPLEMENTACIÓN

SIN BALA DE PLATA: El índice óptimo se dicta por objetivos de recall, tamaño de dataset, dimensionalidad y requisitos de latencia.

DOMINIO DE PARÁMETROS: M, efConstruction, efSearch para HNSW; k, nprobe para IVFFlat.

ENFOQUES HÍBRIDOS: Combinar técnicas (IVF para grueso, HNSW para fino) frecuentemente produce resultados superiores.

EVALUACIÓN CONTINUA: El benchmarking es esencial para validar elecciones de configuración.
