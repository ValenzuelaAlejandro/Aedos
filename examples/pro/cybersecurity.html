ESCANEANDO VULNERABILIDADES

> THREAT LANDSCAPE

Malware

Software diseñado para infiltrarse o dañar un sistema sin el consentimiento del usuario (virus, troyanos).

Phishing

Técnicas de engaño para obtener información sensible suplantando una fuente de confianza.

Ransomware

Secuestro de datos mediante cifrado, exigiendo un rescate económico para su liberación.

Ataques DDoS

Sobrecarga de servicios con tráfico masivo para interrumpir su funcionamiento normal.

VULNERABILIDAD HUMANA

> SOCIAL ENGINEERING

Pretexting

Creación de un escenario falso para obtener información o acceso privilegiado.

Baiting

Uso de un señuelo (como un USB infectado) para tentar a la víctima a comprometer su sistema.

Quid Pro Quo

Promesa de un beneficio o servicio a cambio de información o acceso técnico.
