02 • ARCHITECTURE

DECENTRALIZED

Server dependency is eliminated. Every clone is a full backup.

  • Offline First: No internet required for commits or branches.
  • Redundancy: 100 distributed copies of data.
  • Forking: Isolation of experimental logic.
TRADITIONAL

CENTRALIZED (SVN)

Master server holds the only source of truth. Client is a thin view of history.

  • Server Bound: No history, no branches, no commits without server.
  • Single Point of Failure: Database corruption risks everything.
  • Linear History: Harder to sandbox complex experiments.
