02 · CONCEPT

Rebasing vs. Merging

Understanding the nuances of `git rebase` and `git merge` for cleaner commit histories.

Merge

Preserves history, creates merge commits.

Rebase

Rewrites history, creates linear history.

When to Use

Rebase for feature branches, merge for shared branches.
